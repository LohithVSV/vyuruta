Vyuruta is a coding strategy game where players choose Fire or Water, claim territories, and compete through coding battles. Solve challenges to win treasure, build your streak, and climb the weekly and seasonal leaderboards. The game also features a daily coding question with its own leaderboard, a world map, and daily treasure rewards. Seasons run for 28 days.

Key features

Explore the world map and view claimed territories.
Challenge other players to timed coding battles.
Solve a daily coding question for a treasure reward.
Compete on weekly, seasonal, and daily-question leaderboards.
Seed daily questions from the backend.
